# hotel-booking-analysis-powerbi

## 📊 Project Overview

This project analyzes hotel booking data to identify booking trends,
cancellation patterns, pricing behavior, and customer booking channels.

The data was first cleaned and analyzed using Microsoft Excel,
then visualized and transformed into an interactive dashboard using
Microsoft Power BI.

## 🎯 Objectives

- Analyze overall booking performance
- Monitor cancellation rates
- Identify booking trends over time
- Analyze booking channels and market segments
- Compare average room prices
- Understand the relationship between lead time and booking status

## 🛠️ Tools & Technologies

- Microsoft Excel — Data Cleaning & Analysis
- Microsoft Power BI — Data Visualization & Dashboard Development

## 📌 Dashboard KPIs

- Total Bookings
- Confirmed Bookings
- Cancellation Rate
- Average Room Price
- Total Revenue

## 📈 Dashboard Features

- Booking trends by year and month
- Booking status analysis
- Market segment analysis
- Average room price analysis
- Lead time analysis
- Interactive filters for guest type and room type

## 🔍 Key Insights

- Online bookings represent the largest booking segment.
- A significant portion of bookings were canceled.
- Booking activity varies across months and years.
- Room prices differ across room types.
